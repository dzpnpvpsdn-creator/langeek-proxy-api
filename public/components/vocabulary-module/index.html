❓ 3. FAQ

Q: Có cần đăng ký gì không?
A: Không. Hoàn toàn miễn phí, không cần key, không cần tài khoản.
Q: Tải nhiều có bị reload không?
A: Không. Chọn folder 1 lần → các file sau ghi trực tiếp vào folder đó, không có popup → không reload.
Q: Proxy là gì? Cần chạy không?
A: Proxy chạy local, cần bật bằng npm start trong thư mục langeek-proxy.
